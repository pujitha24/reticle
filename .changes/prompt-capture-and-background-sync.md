### Added

- **`@reticlehq/init`, `@reticlehq/server` — each prompt you send is kept in `.reticle/`, without the agent having to relay it.** The user's request is what a verdict is checked against, and an agent relayed it only when it remembered to. `reticle init` now installs a prompt-submit hook, at project level, for each agent it finds that has one: Claude Code, Cursor, Codex CLI, Gemini CLI, Windsurf, VS Code Copilot and Copilot CLI, and Factory Droid. The hook runs `reticle hook prompt`, which removes secrets, splits and classifies the statements, writes `.reticle/request.json`, and adds a line to `.reticle/requests.jsonl`. It never blocks a prompt. Agents with no prompt hook, such as Claude Desktop, are told by the MCP instructions to declare the request once for each user request. The prompt never enters telemetry. It reaches your own linked workspace only inside a run, and only when the project shares requests. To turn it off, use `--no-prompt-capture`, `"promptCapture": false` in `.reticle.json`, or `reticle hook uninstall`, which removes exactly what was added. `reticle hook status` and `reticle doctor` show, for each agent, whether its prompts are captured.

### Changed

- **`@reticlehq/server` — background sync runs only while you are signed in, and never sends to an address from the environment.** The daemon sends a linked project's runs, flows and memory without `reticle sync`. It now does this only when the project is linked by its own `.reticle/cloud.json` and somebody is signed in to that address. The address comes from the link, never from `RETICLE_CLOUD_URL`, so a repository `.env` cannot send one app's runs to another workspace. After `reticle logout`, it stops on the next check. When the platform refuses the key (401 or 403), it stops until you sign in again. After a network error, it waits longer each time, up to 15 minutes. It checks for local changes every 30 seconds and makes no network call when nothing changed. Turn it off with `"backgroundSync": false` in `.reticle.json` or `RETICLE_BACKGROUND_SYNC=0`. `reticle doctor` shows whether it is on, the reason when it is off, the last push and the last error.
